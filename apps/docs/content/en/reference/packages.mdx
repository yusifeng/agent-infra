# Package Map

## `@agent-infra/core`

Defines:

- domain types
- repository interfaces
- durable record semantics

## `@agent-infra/contracts`

Defines:

- serialized request and response shapes
- consumer-facing contract exports

## `@agent-infra/db`

Implements:

- SQLite repositories
- PostgreSQL repositories
- schema and migration flow

## `@agent-infra/app`

Provides:

- thread use cases
- turn use cases
- the stable consumer boundary

## `@agent-infra/runtime-pi`

Provides:

- server-side runtime execution
- provider/model selection
- durable persistence mapping for runtime events

## `apps/playground-next-web`

Acts as:

- the first consumer of the platform
- an experiment harness
- a runtime console, not the domain boundary

## `apps/playground-vite-web`

Acts as:

- a Vite-based browser consumer scaffold
- the place to validate `@agent-infra/durable-chat-client` outside Next.js
- a future home for side-by-side UX parity checks against the Next consumer

## `apps/playground-fastify-server`

Acts as:

- a Fastify-based server scaffold
- the place to validate `@agent-infra/durable-chat-server` outside Next.js
- a future host for route wiring parity checks against the Next server surface
