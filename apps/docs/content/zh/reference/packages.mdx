# Package 地图

## `@agent-infra/core`

定义：

- domain types
- repository interfaces
- durable record 语义

## `@agent-infra/contracts`

定义：

- 序列化后的 request / response shapes
- 面向使用方的 contract exports

## `@agent-infra/db`

实现：

- SQLite repositories
- PostgreSQL repositories
- schema 与 migration flow

## `@agent-infra/app`

提供：

- thread use cases
- turn use cases
- 稳定的 consumer boundary

## `@agent-infra/runtime-pi`

提供：

- 服务端 runtime execution
- provider/model selection
- runtime events 到 durable records 的持久化映射

## `apps/playground-next-web`

它的定位是：

- 平台的第一个使用方
- 一个实验载体
- 一个 runtime console，而不是 domain boundary

## `apps/playground-vite-web`

它的定位是：

- 一个基于 Vite 的浏览器使用方骨架
- 用来在 Next.js 之外验证 `@agent-infra/durable-chat-client`
- 后续可用于和 Next 使用方做 UX 对照验证

## `apps/playground-fastify-server`

它的定位是：

- 一个基于 Fastify 的服务端骨架
- 用来在 Next.js 之外验证 `@agent-infra/durable-chat-server`
- 后续可用于和 Next 服务端表面做 route wiring 对照验证
